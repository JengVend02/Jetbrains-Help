使用说明

详细的激活步骤和配置说明

代理配置

  1. 下载 工具包
  2. 解压后放入 不包含中文路径 的任意目录
  3. 之前使用过代理工具：
    • windows
      • 先执行 /scripts/uninstall-all-users.vbs 等待 Done 弹窗
      • 再执行 /scripts/install-current-user.vbs 等待 Done 弹窗
    • mac
      • 调用控制台执行 /scripts/uninstall.sh 等待 Done 输出
      • 再调用控制台执行 /scripts/install.sh 等待 Done 输出
  4. 之前未使用过代理工具：
    • windows
      • 执行 /scripts/install-current-user.vbs 等待 Done 弹窗
    • mac
      • 调用控制台执行 /scripts/install.sh 等待 Done 输出
  5. 重启电脑（重要）

    必须重启才能使配置生效！

产品激活

  1. 激活码方式：在 页面生成产品或插件激活码
  2. 服务器方式：将 填入【许可证服务器-服务器地址】
  3. JRebel激活：将 填入【Team URL】，邮箱随意填写
